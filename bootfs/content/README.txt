ShowPlayPI Local Content
=======================

Place local HTML files and related assets in this directory.

To open index.html, enter this URL in showplaypi.ini:

file:///boot/firmware/content/index.html

Important:
- Use three slashes after file:
- Use forward slashes.
- File and directory names are case-sensitive.
- Avoid spaces and special characters in filenames.
- Relative links, images, scripts and stylesheets inside the content directory
  can be used normally.

Example:
URL=file:///boot/firmware/content/index.html
