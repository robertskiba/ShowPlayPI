ShowPlayPI – local web pages
============================

Put your own HTML pages with their images, scripts and stylesheets into this
folder (HTML on the SHOWPLAYPI drive).

To show index.html, enter this URL in showplaypi.ini or in the configurator:

    file:///media/showplaypi/HTML/index.html

Notes:
- Use three slashes after "file:" and forward slashes.
- File and folder names are case-sensitive.
- Avoid spaces and special characters in file names.
- Relative links, images, scripts and stylesheets work normally.
