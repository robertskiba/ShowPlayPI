SHOWPLAYPI CONFIGURATION
========================

This drive contains the configuration file for ShowPlayPI.

Configuration
-------------

Edit showplaypi.ini with a plain text editor or use the ShowPlayPI Configurator
application for Windows.

The changed configuration is checked and applied during the next ShowPlayPI
startup. Network, display and browser settings do not change immediately.

Important
---------

- Keep the file name showplaypi.ini unchanged.
- Do not format this drive.
- Do not delete or rename README.txt.
- After saving, the USB cable may be disconnected.
- Invalid settings are rejected automatically.
- The previous working configuration is retained if validation fails.

Initial configuration
---------------------

The same showplaypi.ini file is also available on the SD card boot partition.
Changes made through either configuration method are synchronized when
ShowPlayPI starts.
